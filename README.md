# SUZI

**Intelligence for everyone.**

SUZI is an emerging human-centered open-source AI initiative by **The Wealth Salons**, developed with build partner **Lumenfolk**. The project explores small portable models, source-grounded answers, user-controlled personalization, and practical evaluation methods intended to help everyday people navigate information and opportunities.

**Status:** Early-stage design and scaffolding. The public repository currently contains an approved v0.1 visual identity and a proposed holding-page source. No model migration, benchmark outcome, production deployment, funding award, or external adoption is claimed.

- [Visual identity and usage rules](brand/README.md)
